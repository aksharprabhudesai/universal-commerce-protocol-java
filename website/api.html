API Reference

Reference documentation for SPI adapters, resilience decorators, domain models, configuration properties, and discovery metadata.

Core Interface: CommerceAdapter

The root Service Provider Interface (SPI) for all commerce capabilities. Implementations wire this interface to communicate with specific commerce backends.

Methods

  • CatalogAdapter getCatalogAdapter(): Returns the adapter for catalog search and lookup (or null if unsupported).
  • CartAdapter getCartAdapter(): Returns the adapter for shopping cart operations (or null if unsupported).
  • default CheckoutAdapter getCheckoutAdapter(): Returns the adapter for checkout session operations (defaults to null if unsupported).
  • OrderAdapter getOrderAdapter(): Returns the adapter for order management operations (or null if unsupported).
  • CustomerAdapter getCustomerAdapter(): Returns the adapter for customer / identity operations (or null if unsupported).

Capability Adapters

CatalogAdapter

Advertised as dev.ucp.shopping.catalog.search and dev.ucp.shopping.catalog.lookup in discovery.

  • Optional<Product> getProductById(String id): Fetch a single product by ID.
  • List<Product> searchProducts(String query): Search products by keyword query.
  • List<Product> getProductsByCategory(String categoryId): Retrieve products in a category.

CartAdapter

Advertised as dev.ucp.shopping.cart in discovery.

  • Cart getCart(String cartId): Retrieve a cart by identifier.
  • Cart createCart(String customerId): Create a new cart for a customer.
  • Cart addToCart(String cartId, String productId, int quantity): Add items to an existing cart.
  • Cart removeFromCart(String cartId, String itemId): Remove an item from a cart.
  • Cart updateItemQuantity(String cartId, String itemId, int quantity): Update the quantity of an item in the cart.

CheckoutAdapter

Advertised as dev.ucp.shopping.checkout in discovery.

  • Checkout createCheckout(Cart cart): Initiate a checkout session from a cart.
  • Optional<Checkout> getCheckout(String checkoutId): Retrieve a checkout session by ID.
  • Checkout updateCheckout(String checkoutId, Checkout checkout): Update an active checkout session.
  • Checkout completeCheckout(String checkoutId): Complete checkout and finalize order placement.
  • Checkout cancelCheckout(String checkoutId): Cancel an active checkout session.

OrderAdapter

Advertised as dev.ucp.shopping.order in discovery.

  • Order createOrder(String cartId): Create an order from a cart identifier.
  • Order getOrder(String orderId): Retrieve order details by order ID.
  • List<Order> getOrdersByCustomer(String customerId): List orders placed by a customer.
  • Order cancelOrder(String orderId): Cancel an existing order.

CustomerAdapter

Advertised as dev.ucp.common.identity_linking in discovery.

  • Optional<Customer> getCustomer(String id): Retrieve customer profile by ID.
  • Customer createCustomer(Customer customer): Register or link a new customer record.
  • Customer updateCustomer(String id, Customer customer): Update an existing customer record.

Resilience

ResilientCommerceAdapter

Decorates any CommerceAdapter with a Resilience4j CircuitBreaker and Retry while preserving null capability semantics. Automatically applied by UcpAutoConfiguration when Resilience4j registries are active (controlled via ucp.resilience.*).

Configuration & Discovery

UcpProperties (prefix ucp)

  • ucp.provider: Active commerce provider (mock by default, shopify, etc.).
  • ucp.endpoint: Provider backend endpoint URL.
  • ucp.api-key: Provider API key.
  • ucp.api-secret: Provider API secret.
  • ucp.services.rest-endpoint: Advertised REST transport endpoint for dev.ucp.shopping.
  • ucp.services.mcp-endpoint: Advertised Model Context Protocol (MCP) transport endpoint.
  • ucp.services.a2a-endpoint: Advertised Agent-to-Agent (A2A) agent card URL.
  • ucp.services.embedded-enabled: Advertise the embedded OpenRPC shopping transport (false by default).
  • ucp.resilience.enabled: Automatically wrap CommerceAdapter beans with Resilience4j (true by default).
  • ucp.resilience.instance-name: Resilience4j instance name for circuit breaker and retry lookups (ucp by default).

Discovery Endpoint (/.well-known/ucp)

Automatically exposed when Spring Boot Web MVC and a CommerceAdapter bean are present. Conforms to the UCP 2026-08-25 specification profile schema.
