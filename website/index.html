What is UCP?

The Universal Commerce Protocol (UCP) is an open standard that defines a unified interface for commerce operations. It abstracts away the complexity of different e-commerce backends (Shopify, Magento, Salesforce, etc.) into a single, consistent API.

UCP Java is the Spring Boot 4 starter for the JVM, aligned with UCP specification 2026-08-25. It provides:

  • A unified domain model (Product, Cart, Checkout, Order, Customer)
  • Standardized Service Provider Interfaces (SPIs) with Resilience4j circuit breakers & retries
  • Automatic discovery at /.well-known/ucp advertising REST, MCP, A2A, and Embedded transports
  • A runnable, stateful sample storefront (examples/ucp-example) ready for any AI agent

Who is this for?

🤖 Agentic Commerce

Make your storefront immediately discoverable and operable by AI agents via /.well-known/ucp, Model Context Protocol (MCP), REST, and Agent-to-Agent (A2A) transports.

🚀 Platform Builders

Building a SaaS that needs to integrate with your customers' existing stores? Write your integration once against UCP and support every major commerce backend instantly.

🏢 Enterprise Teams

Migrating from a monolith to microservices or unifying multiple brands? Use UCP as an anti-corruption layer to standardize commerce logic across your organization.

Why UCP?

⚡ Unified Domain Model

Stop mapping JSON manually. Use standardized Product, Cart, Checkout, Order, and Customer POJOs across any backend.

🔧 Spring Boot 4 Native

Zero-boilerplate auto-configuration with IDE metadata. Add the starter, define your properties, and inject CommerceAdapter.

🔌 Extensible SPI

Need to support a custom backend? Implement clean capability interfaces (CatalogAdapter, CartAdapter, CheckoutAdapter) and UCP handles discovery and resilience.

🛡️ Resilience Built-in

Production-grade by default. Circuit breakers and retries via Resilience4j automatically guard every CommerceAdapter operation.

Quick Install

Requires Spring Boot 4.x and Java 17+ (use 0.0.1 for Spring Boot 3.x).

Gradle

// build.gradle
dependencies {
    implementation 'dev.ucomprotocol:ucp-spring-boot-starter:0.2.0'
}

Maven

<!-- pom.xml -->
<dependency>
    <groupId>dev.ucomprotocol</groupId>
    <artifactId>ucp-spring-boot-starter</artifactId>
    <version>0.2.0</version>
</dependency>

Simple Usage

@Service
public class ProductService {
    private final CommerceAdapter commerceAdapter;

    public ProductService(CommerceAdapter commerceAdapter) {
        this.commerceAdapter = commerceAdapter;
    }

    public Product getProduct(String id) {
        return commerceAdapter.getCatalogAdapter()
            .getProductById(id)
            .orElseThrow();
    }
}

Test with Any AI Agent

Run the bundled sample storefront (examples/ucp-example) to test all 6 UCP capabilities over MCP (/ucp/mcp), REST (/ucp/v1), and A2A (/.well-known/agent-card.json):

claude mcp add --transport http ucp-store http://localhost:8082/ucp/mcp
