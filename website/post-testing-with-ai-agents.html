Testing Guide · UCP Java 0.2.0

How to Run and Test UCP Java 0.2.0 Locally with Any AI Agent

Published: November 11, 2026 Library Version: 0.2.0 UCP Spec: 2026-08-25 Read Time: 7 min

With UCP Java 0.2.0 (dev.ucomprotocol:ucp-spring-boot-starter:0.2.0), Spring Boot 4 applications gain complete Universal Commerce Protocol 2026-08-25 support—including the new CheckoutAdapter capability, automatic Resilience4j circuit-breaker and retry decoration, optional Web MVC auto-configuration, and multi-transport discovery at /.well-known/ucp.

To make local verification effortless, the repository includes a stateful, agent-ready reference storefront in examples/ucp-example. This post walks through every way you can run and test UCP Java locally—from automated JUnit suites and curl commands to live autonomous purchases with Claude Code, Cursor, Gemini CLI, or custom HTTP/A2A agents.

Prerequisites: Java 17+ (the repository includes the Gradle 9.9.1 wrapper, so no separate Gradle install is needed).

1. What the Sample Storefront Exposes

The sample app wires an in-memory CommerceAdapter (InMemoryStoreAdapter) seeded with 6 products and demo customer cust-demo-01 (alex@example.com). All operations are automatically wrapped in Resilience4j CircuitBreaker and Retry via ResilientCommerceAdapter.

Capability / Endpoint Path / Identifier What You Can Test
UCP Discovery GET /.well-known/ucp Canonical UCP 2026-08-25 profile advertising 3 transports and 6 capabilities
MCP Streamable HTTP POST /ucp/mcp JSON-RPC 2.0 MCP server exposing 16 typed shopping & identity tools
REST Shopping API /ucp/v1/* /catalog/search, /catalog/lookup, /carts, /checkout-sessions, /orders, /customers
A2A Agent Card GET /.well-known/agent-card.json Agent-to-Agent discovery metadata and 5 commerce skills

2. Start the Storefront & Run Automated Tests

Clone the repository and run both the starter test suite and the sample storefront integration tests:

git clone https://github.com/aksharprabhudesai/universal-commerce-protocol-java.git
cd universal-commerce-protocol-java

# Run starter unit & auto-configuration tests (20 tests)
./gradlew test

# Run sample storefront end-to-end REST, MCP & Discovery tests
./gradlew -p examples/ucp-example test

Now launch the live storefront server on http://localhost:8082:

./gradlew -p examples/ucp-example bootRun

Verify the UCP 2026-08-25 discovery document and A2A agent card in a second terminal:

curl -s http://localhost:8082/.well-known/ucp | python3 -m json.tool
curl -s http://localhost:8082/.well-known/agent-card.json | python3 -m json.tool

3. Test with MCP-Compatible AI Agents

Any Model Context Protocol client that supports Streamable HTTP (Claude Code, Cursor, Claude Desktop, Gemini CLI, Antigravity) can connect directly to http://localhost:8082/ucp/mcp.

Claude Code CLI

claude mcp add --transport http ucp-store http://localhost:8082/ucp/mcp

Cursor / Claude Desktop / Gemini CLI (mcpServers JSON)

{
  "mcpServers": {
    "ucp-store": {
      "url": "http://localhost:8082/ucp/mcp"
    }
  }
}

Sample Prompts to Try

  1. "Search the UCP store for coffee gear under $200 and list what is available."
  2. "Create a cart for customer cust-demo-01, add 1 conical burr grinder and 2 ceramic espresso cup sets, and tell me the live cart total."
  3. "Create a checkout session from that cart, complete the checkout, and report the confirmed order ID and total."
  4. "Fetch all orders placed by cust-demo-01, then cancel the order we just created."

4. Test with Autonomous HTTP or A2A Agents

Agents built with LangChain, LangGraph, CrewAI, OpenAI, or Gemini that have an HTTP fetch tool can self-discover the storefront's schemas and endpoints without pre-configured MCP tools. Give your agent this prompt:

"Inspect http://localhost:8082/.well-known/ucp (or http://localhost:8082/.well-known/agent-card.json), discover the merchant's supported capabilities and transport endpoints, and purchase a wireless mechanical keyboard and smart digital coffee scale for customer cust-demo-01."

5. Test End-to-End from Terminal with curl

Option A: MCP JSON-RPC 2.0 Flow (/ucp/mcp)

# 1. Initialize MCP session
curl -s -X POST http://localhost:8082/ucp/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","clientInfo":{"name":"curl-test","version":"1.0"}}}' | python3 -m json.tool

# 2. List all 16 registered UCP tools
curl -s -X POST http://localhost:8082/ucp/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' | python3 -m json.tool

# 3. Call search_catalog
curl -s -X POST http://localhost:8082/ucp/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"search_catalog","arguments":{"category":"coffee"}}}' | python3 -m json.tool

Option B: Canonical REST Flow (/ucp/v1)

# 1. Search catalog
curl -s -X POST http://localhost:8082/ucp/v1/catalog/search \
  -H "Content-Type: application/json" \
  -d '{"query":"espresso"}' | python3 -m json.tool

# 2. Create cart with 1 grinder ($149) + 2 cup sets ($68) = $217.00
curl -s -X POST http://localhost:8082/ucp/v1/carts \
  -H "Content-Type: application/json" \
  -d '{"customerId":"cust-demo-01","items":[{"productId":"prod-grinder-02","quantity":1},{"productId":"prod-mugs-03","quantity":2}]}' | python3 -m json.tool

# 3. Create checkout session (replace cart-1001 if needed)
curl -s -X POST http://localhost:8082/ucp/v1/checkout-sessions \
  -H "Content-Type: application/json" \
  -d '{"cartId":"cart-1001"}' | python3 -m json.tool

# 4. Complete checkout -> creates CONFIRMED order
curl -s -X POST http://localhost:8082/ucp/v1/checkout-sessions/chk-2001/complete | python3 -m json.tool

# 5. Verify placed order
curl -s http://localhost:8082/ucp/v1/orders/ord-3001 | python3 -m json.tool

6. Testing UCP Java in Your Own Spring Boot 4 App

When integrating dev.ucomprotocol:ucp-spring-boot-starter:0.2.0 into your own service, UCP Java registers MockCommerceAdapter automatically whenever ucp.provider=mock (the default) and no custom CommerceAdapter bean is present—making integration testing immediate without external credentials:

@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
class StorefrontUcpDiscoveryTest {

    @Autowired
    private CommerceAdapter commerceAdapter;

    @Test
    void mockAdapterSupportsCheckoutLifecycle() {
        Cart cart = commerceAdapter.getCartAdapter().createCart("cust-1");
        Checkout checkout = commerceAdapter.getCheckoutAdapter().createCheckout(cart);
        Checkout completed = commerceAdapter.getCheckoutAdapter().completeCheckout(checkout.getId());

        assertEquals(Checkout.CheckoutStatus.COMPLETED, completed.getStatus());
        assertNotNull(completed.getOrderId());
    }
}
